## What I do

I hunt for impactful vulnerabilities in web and cloud applications — auth flaws,
access-control issues, injection, SSRF and misconfigurations — and write them up
so they can be reproduced and fixed.

- Web and API security testing
- Cloud misconfiguration review
- Responsible disclosure and clear proof-of-concept write-ups
